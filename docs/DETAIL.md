# dsh-zsearch

在 DeepSeek Harness 中同时检索知乎与全网：左侧是流式 AI 综述，右侧是可逐字核对的引用来源。回答里的 `[1]`、`[2]` 角标可以点击，直接定位到证据卡。

## 功能

- **双源检索**：同时查询知乎与全网，候选合并、去重、排序。
- **左答右证**：流式回答 + 按视角分组的引用卡。
- **引用核对**：未被分组的引用候选会自动补到「其他参考内容」。
- **Markdown 回答**：标题、列表、表格、代码块、引用、链接、图片。
- **划词检索**：选中对话文本后点击浮层直接检索。
- **状态持久化**：切走或刷新后恢复上次结果。

## 安装

桌面端：**Plugins → Add plugin**，输入 `dsh-zsearch`，或选择本地目录。安装/更新 Host 代码后重启 DSH。

CLI：

```sh
dsh plugin --profile <profile> add dsh-zsearch
```

## 环境要求

- DeepSeek Harness `>=0.2.2-rc.3 <0.3.0`。
- Node.js `>=24.9.0`。
- 本机 `zhihu-cli` 与知乎 Access Secret；首次使用会显示三步引导。
- DSH 中已配置可用的默认模型。

## 权限与隐私

- Host 只监听 `127.0.0.1`，无遥测、无外部上报。
- 检索通过本机 `zhihu-cli` 完成；回答与筛选使用 DSH 宿主模型。
- Access Secret 写入系统钥匙串；钥匙串不可用时回退宿主 `credentials`，不写入仓库或日志。
- 头像只代理 `zhimg.com` 的 HTTPS 图片，限制 512KB。
- 面板状态保存在 Web GUI 的 `localStorage`，不包含 Secret。

## 兼容与限制

- 已在 DSH `0.2.2-rc.3` 上验证。
- 回答基于候选原文生成，右栏是筛选摘句，不保证逐字同源。
- 回答输入约 1.3 万字符，成本和延迟高于轻量检索。
- 回答被 provider 中断或超时时保留已生成部分，不自动续写。

## 开发

仓库内运行 `npm run verify`；npm 包不包含测试文件。测试使用假 CLI / 假模型，不消耗真实额度。
